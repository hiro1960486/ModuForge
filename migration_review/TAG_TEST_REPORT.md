## Windows 11 ユーザー試験での検出事項・修正（2026-10-09）
- 旧版はWindows実機で9件中、失敗1件・エラー9件。以前のLinux環境の9件合格をWindows合格とみなさない。
- `PermissionError [WinError 32] tags.db`: SQLiteの`with connection:`は接続を閉じないため、一時フォルダー削除時にハンドルが残る可能性があった。`contextmanager`による確実な`close()`を追加。
- `AssertionError` パス大小文字: サービスが`normcase()`で検索用キーを正規化する仕様に対し、試験が未正規化の文字列を期待していた。試験期待値を仕様に合わせて修正。
- 修正後のWindows 11実機での再検証は未実施。**Windows合格判定は保留**。

- 統合アプリ本体への実装・起動確認・回帰試験は未実施。これは独立研究・試験パックです。

## 操作手順 (Windows 11)
1. ZIPを `C:\FW_Test` など短いパスに展開。
2. `FW33` フォルダーで PowerShell またはコマンドプロンプトを開く。
3. `py -m pip install -r requirements.txt`
4. `py run_component.py tags`
5. 「ファイルを追加」でテスト用ファイルを選択。
6. タグをカンマ区切りで入力し「タグを保存」。
7. 画像/音声/動画のプレビュー・基本情報を確認。
8. 「移動先を選択」で空のテストフォルダーを選択し「選択ファイルを移動」を押す。移動元・移動先を確認してから「はい」。
9. 非GUIテストは `py test_tags.py` 。
