## Windows実機からの不具合修正（GUI起動 v3）
- 報告: `AttributeError: 'OrganizerModule' object has no attribute 'bind_port'`。
- 原因: 共通 `WidgetModuleAdapter.connect_widget()` が要求する `bind_port` がファイル整理GUIに欠落。
- 修正: `OrganizerModule.bind_port()` と `self.port` を追加。
- 追加修正: `08_organizer/api/module.json` の誤った `tags` 起動先を `organizer` へ訂正。
- 回帰試験: GUI接続契約（AST）・manifestの整合性をテスト追加。
- 制約: PySide6がこの環境にないため、Qtウィンドウを使う実機起動試験はWindows側で要確認。
