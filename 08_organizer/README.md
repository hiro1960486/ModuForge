# 08 ファイル整理モジュール仕様

- 目的: 元ファイル情報を確認し、移動先を選択し、安全なコピー・移動を試験する。
- API: inspect(path), plan(path,destination,action), execute(plan,confirm=true)。
- コピー: 排他的に新規作成しSHA-256を照合。既存ファイルを上書きしない。
- 移動: 同一ファイルシステム内のみ。異なるボリュームは安全停止。
- 未実装: ごみ箱削除、コピー後削除、Undo、バッチ、右クリックUI、専用メディアプレビュー。
- 警告: 元データを移動しないこと。sample_dataで試験すること。
