# ModuForge プロジェクト概要

ModuForgeは再利用可能なPythonモジュール・APIの研究、単独試験、統合試験、保守を目的とした独立プロジェクトです。FileWorkbench Nextは初期部品の由来および想定接続先の一つです。

## 管理原則
1. モジュール本体とAPI契約を分離する
2. UIや特定アプリに依存する部分を明示する
3. 危険なファイル操作は実行前の確認を必須にする
4. 修正ごとに単独試験と回帰試験を行う
5. ログはアプリ側の共通基盤で管理し、GitHubには上げない

現行の開発対象はリポジトリ直下の `00_shared/` と `01_tree/`〜`08_organizer/` に配置します。旧 `FW33/` は移行中の完全性検査・切り戻し用に一時保管しています。
